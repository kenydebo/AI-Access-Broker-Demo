Technical limits

The server process permits 20 reserved runs per rolling 24 hours and 4 per minute, with at most 2 provider attempts per run. Failed calls and runs with no tool call still consume reservations. These are demo safeguards, not Google's provider quota. Sessions and counters are in memory and are lost on restart; this is not a durable billing cap.
